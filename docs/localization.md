# Языки и регион

Фиксированные словари `frontend/src/locales/{ru,en,cs,de}/translation.json`. Все интерфейсные подписи, ошибки, уведомления, меню и формы используют i18next. Названия компаний и пользовательские данные не переводятся. Fallback для отсутствующих ключей — en. `localStorage.locale` хранит только язык, не авторизацию. До входа берётся сохранённый выбор или navigator.language; после входа — preferred_locale профиля. Переключение авторизованного пользователя сохраняется PATCH /profile, затем меняет словарь. DEFAULT_LOCALE — региональный язык по умолчанию, возвращаемый /config; браузерный язык имеет приоритет, при неподдерживаемом браузерном языке используется DEFAULT_LOCALE.

Добавляя строки, обновляйте все четыре словаря. `npm test` проверяет совпадение ключей и работу i18next для каждого языка. Формат дат через Intl.DateTimeFormat, чисел через Intl.NumberFormat; часовой пояс даты берётся из текущей компании. API передаёт даты ISO 8601. HTML lang синхронизируется с языком.

APP_REGION ru/eu не ограничивает язык кабинета, default_locale компании или язык ассистента. Например, EU-компания может использовать русский интерфейс и немецкий язык ассистента. Языковая политика ассистента сохраняется как настройка, inference отсутствует.
