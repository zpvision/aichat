# Cosmic Violet — этап 9А.2

Исходный HEAD: `5ebbe9406410b19300d93a8a7c9502380e6ad657`. Новый маркетинг не меняет backend, AI/RAG, подписки или завершённую S3-интеграцию. Кабинет и публичный iframe-виджет сохраняют прежние стили.

## Маршруты и архитектура

- `/` — публичный маркетинг, включая авторизованных пользователей.
- `/?lang=ru|en|cs|de` — язык. Сохраняется существующая настройка `locale`, используемая и при переходе в регистрацию.
- `/register`, `/login` — прежние формы. После входа `/app`.
- `/app` — прежний кабинет. Приглашения `/#invite=…` используют прежний обработчик.

`src/main.tsx` лениво выбирает `marketing/Landing.tsx` или `Workspace.tsx`. Workspace получен переносом существующего приложения с минимальными изменениями маршрутов. Его CSS загружается отдельно; маркетинговые селекторы начинаются с `.cosmic`. Widget не импортирует их. Старые browser-тесты изменены только в адресах открытия кабинета, включая opt-in S3-сценарий.

## Визуальная система и оригинальные материалы

Scoped tokens в `src/marketing/cosmic.css`: deep `#140D33`, violet `#5530C8`, purple `#9957E8`, pink `#ED91DD`, light/lavender/white/text/muted. Тёмный Hero сменяется белыми и лавандовыми секциями; передача человеку, аналитика и финальный CTA создают тёмные акценты. Розовый ограничен свечениями, графиками и текстом градиента.

Manrope variable 400–800, кириллица/латиница/расширенная латиница, хранится локально в `public/fonts`, font-display:swap. Источник Google Fonts, лицензия OFL приложена; runtime-запросов к Google нет.

Оригинальная графика создана кодом: SVG-лента из 19 кривых, фирменный знак диалоговой нити, документы → консультант, AI Chat → API/Webhook → CRM, линии и области графиков, sparklines. Продуктовые композиции показывают чат, заявку, историю и передачу человеку. `cosmic-social.svg` — отдельная авторская композиция; PNG для Open Graph воспроизводится `node scripts/generate-social.mjs` (экспорт SVG, не скриншот пользовательских данных). Изображения и тексты Chatix не копировались.

Реализованы все 13 секций задания. Тарифы Trial/Start/Business представлены без вымышленных цен и численных лимитов. Действующие лимиты остаются в кабинете. Все CTA начала работы ведут в регистрацию. Настоящий Trial назначается прежним backend при создании компании.

## Демо и анимации

Четыре сценария: услуга, стоимость, заявка, сотрудник. Вопрос → индикатор набора → ответ → подтверждение/передача. Работает повтор. Подтверждение примера меняет только React state. Модель, extractor, лиды и квоты не вызываются. Единственный запрос страницы — read-only `/api/v1/config` для публичного бренда; без него остаётся AI Chat.

Все данные синтетические, режим явно назван сценарным. Вкладки интерфейсов и отраслей работают. Dashboard с обращениями, лидами, конверсией и передачами маркирован как концепт; новый рабочий раздел аналитики не создан.

CSS-анимации: staged Hero, движение света, плавание карточки, последовательность сообщений, reveal через IntersectionObserver, линии схем, прорисовка графиков, hover. Без новой библиотеки, видео, автоматического скролла или parallax. `prefers-reduced-motion` отключает движение и показывает контент сразу. Размеры сцен зарезервированы.

## Доступность, SEO и адаптивность

Семантические main/section/header/footer, один H1, H2 секций, skip-link, focus-visible, Escape для меню, стрелки/Home/End для вкладок, native details/summary для 9 FAQ. Декоративные SVG скрыты от screen reader, графики подписаны как концепт. Проверены 360/390/768/1024/1440/1920 px, включая длинные DE/CS строки. На телефоне сохранена продуктовая композиция.

Title, description, html lang, canonical, hreflang и Open Graph обновляются по языку. Index содержит английские начальные метаданные и social PNG. Это React/Vite SPA: контент и локализованные метаданные требуют JS; социальные краулеры без JS получают английский fallback. SSR/prerender, production-домен, sitemap/robots и локализованные social cards не добавлялись. Перед публичным запуском проверить индексацию на фактическом домене.

## Проверки и воспроизведение

Frontend: `npm ci`, `npm test`, `npm run build`, `npm audit`. Новые unit-тесты проверяют полноту словарей, слоганы/CTA и отсутствие mutations из демо. `npx playwright test marketing.spec.ts`: 24 сочетания язык/ширина, метаданные, overflow, demo, FAQ, вкладки, меню, регистрация/вход/настоящий Trial и сохранение после reload.

Browser-тесты используют настоящий Go API и отдельную `site_assistant_marketing_test`, LocalStorage, Mock generation и существующую локальную BGE-M3. S3/.env не читаются, новые S3 live-запросы не выполнялись. Между auth-heavy группами перезапускается только собственный тестовый API. Регрессия: knowledge/preview/widget/workspace; inbox; leads; integrations/billing.

Для лабораторного измерения после build запустить `npx vite preview --host 127.0.0.1 --port 5174`, затем `node scripts/measure-marketing.mjs`. Отчёт: `artifacts/stage9a2/performance.json`. Chromium, холодный cache, CPU ×4, latency 40ms, download 10Mbps, по одному измерению 1440/390. Это не полевые Core Web Vitals и не GPU-тест. Workspace и внешние ресурсы на лендинге не загружаются. Численные результаты — testing.md.

Ограничения: реальная Gemma не проверялась; демо сценарное. Нет новой аналитики, платежей, цен, CRM-коннекторов или deployment. Chromium не заменяет реальную матрицу Safari/Firefox и мобильных устройств.
